# Week 2 Internship Project — Interactive Image Gallery

## Assignment
- Show 6–8 images in a grid
- Clicking an image opens it in a larger lightbox view
- Add hover animations
- Use DOM manipulation and event handling

## Technologies
HTML5, CSS3, JavaScript

## How to run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html`.
4. Hover over the cards and click any image.
5. In the lightbox, use Previous/Next buttons or keyboard Left/Right arrows.
6. Press Escape or the X button to close.

## What to explain in the internship review
- HTML creates the gallery structure and lightbox.
- CSS Grid creates the responsive image grid.
- CSS `transform`, `transition`, and `filter` create hover animation.
- JavaScript selects DOM elements and attaches click events.
- `openLightbox()` changes the image and title dynamically.
- Previous/Next buttons change the current image.
- Keyboard events support Escape and arrow keys.
